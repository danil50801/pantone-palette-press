# Pantone Color Canvas

Build a premium official website concept for PANTONE COFFEE, Kyiv

Create a complete, production-quality, responsive website concept for PANTONE COFFEE, a Ukrainian coffee shop and craft shop in Kyiv.

The website must feel like a direct digital extension of the brand’s Instagram and physical locations.

This is NOT a generic coffee shop template.

The visual direction should be:
editorial + contemporary café + lifestyle brand + modern Ukrainian design + seasonal color campaigns.

The final result should look like a website that a professional design studio created for a real premium coffee brand.

⸻

1. LANGUAGE

The website content must be primarily in Ukrainian.

Brand names and selected editorial labels can remain in English where appropriate:

* PANTONE
* COFFEE
* CRAFT SHOP
* COMMUNITY
* SUMMER
* SEASONAL
* WEEKENDS
* MENU
* LOCATIONS

Do NOT translate the brand name.

Do NOT use Russian anywhere on the website.

The website should feel natural for a Ukrainian audience.

⸻

2. CORE BRAND IDEA

The main idea of the website:

PANTONE IS NOT JUST A COFFEE SHOP.
IT IS A COLOURFUL PLACE THAT CHANGES WITH THE SEASON.

Pantone Coffee combines:

* specialty coffee;
* seasonal drinks;
* desserts and pastries;
* craft products;
* Ukrainian makers;
* a comfortable workspace;
* meetings and social moments;
* pet-friendly atmosphere;
* seasonal products;
* pop-ups and collaborations.

The website should sell the EXPERIENCE of visiting Pantone, not simply list products.

The emotional reaction should be:

“I want to go there.”

⸻

3. VISUAL STYLE

Use a sophisticated editorial layout inspired by:

* modern independent coffee brands;
* fashion/editorial websites;
* contemporary Ukrainian cafés;
* specialty coffee packaging;
* Pantone-like color systems;
* lifestyle magazines;
* high-end restaurant websites.

DO NOT make it look like:

* Starbucks;
* a generic café template;
* a beige coffee website;
* a SaaS landing page;
* a Webflow template;
* an AI-generated generic restaurant website.

Avoid excessive rounded cards, glassmorphism, gradients, huge shadows, generic icons and unnecessary decorative effects.

Use:

* large typography;
* asymmetrical editorial layouts;
* generous whitespace;
* full-width photography;
* strong color blocks;
* visual rhythm;
* large image crops;
* subtle micro-interactions.

The design should feel artistic but still extremely usable.

⸻

5. TYPOGRAPHY

Use a sophisticated editorial typography system.

For large editorial headings:

DM Serif Display

For body text and UI:

Inter or Manrope

Use large typography.

Desktop headings may reach approximately 64–110px.

Mobile headings approximately 42–64px.

Do not make everything bold.

Use contrast between serif editorial headings and clean sans-serif UI text.

20. IMAGE RULES

This is extremely important.

Prioritize authentic Pantone Coffee photography.

Do not use generic stock photos if real Pantone photos are available.

Do not generate fake photos of the Pantone locations and present them as real.

If exact images cannot be sourced automatically, create clearly marked image placeholders with descriptive filenames such as:

pantone-hero.jpg
pantone-coffee.jpg
pantone-ice-cream.jpg
pantone-interior.jpg
pantone-craft-shop.jpg
pantone-location-osokorky.jpg
pantone-location-arsenalna.jpg

The site structure should make replacing images extremely easy.

⸻

21. MOBILE EXPERIENCE

The website will receive significant traffic from Instagram, therefore mobile quality is critical.

Make the site mobile-first.

On mobile:

* hero must be immediately understandable;
* typography remains large;
* buttons must be easy to tap;
* navigation becomes hamburger;
* images remain prominent;
* no horizontal overflow;
* menu remains easy to read;
* location buttons are prominent;
* Instagram CTA is easy to access.

The mobile website must feel designed, not simply compressed from desktop.

⸻

22. ANIMATIONS

Use subtle premium animations:

* fade-in;
* image reveal;
* slide-up;
* smooth scrolling;
* subtle parallax;
* hover image zoom;
* typography reveal;
* color transitions between sections.

Do NOT use:

* excessive particles;
* 3D objects;
* neon effects;
* excessive floating elements;
* constant movement;
* flashy transitions.

The website should feel calm, premium and editorial.

⸻

23. PERFORMANCE

Prioritize performance.

Use:

* lazy loading;
* responsive images;
* WebP/AVIF where possible;
* optimized image dimensions;
* minimal unnecessary JavaScript;
* efficient animations;
* mobile performance optimization.

Do not load a huge gallery immediately.

Hero image should be optimized.

26. CONTENT SAFETY / ACCURACY

This is critical.

Do NOT invent:

* prices;
* menu items;
* events;
* reviews;
* awards;
* employees;
* owners;
* business history;
* statistics;
* customer quotes;
* opening hours;
* addresses.

If information is not verified, either:

1. leave it out;
2. use a clearly marked placeholder;
3. structure the component so it can be filled later.

Do not create fake testimonials.

Do not create fake Google reviews.

⸻

27. BRAND VOICE

The copy should be:

* short;
* warm;
* confident;
* modern;
* slightly editorial;
* human;
* not corporate.

Avoid:

“Welcome to the best coffee shop in Kyiv!”

Avoid exaggerated claims.

Prefer:

Кава, сезонні смаки та місце, куди хочеться повертатися.

The brand should feel confident without trying too hard.

⸻

28. FINAL QUALITY BAR

Before finishing, review the entire website as if it were being presented to the owner of Pantone Coffee.

Ask:

* Does this look like a real premium coffee brand?
* Does it feel connected to Pantone’s visual identity?
* Does the seasonal concept feel natural?
* Is the summer ice cream section visually prominent?
* Are both locations easy to find?
* Does the site look excellent on iPhone?
* Does it feel like an extension of Instagram?
* Is the website visually interesting without becoming chaotic?
* Does it avoid generic AI website aesthetics?
* Are all factual claims based on supplied/verified information?

If any section looks like a generic template, redesign that section.

The final website should feel like a real commercial redesign proposal for PANTONE COFFEE, not an AI-generated demo.
